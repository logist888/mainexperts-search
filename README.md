# MainExperts — поиск и подбор образования

Интерактивный прототип: поиск, уточнение в 3–5 шагов, фильтры по ответам, бюджет, сортировка по цене, список и плитка.

Все программы, цены и изображения демонстрационные. Реальный каталог и ИИ не подключены. Сайт не собирает данные и не отправляет запросы на сервер; используется Google Fonts.

## Запуск

Статический сайт без сборки. Откройте `index.html` или запустите `python -m http.server 8000`.

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root).

Основные файлы: `index.html`, `style.css`, `app.js`. В корне проекта — 10 изображений `.jpg`.
